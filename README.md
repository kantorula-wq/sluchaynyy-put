## Описание проекта

Программа визуализирует **случайное блуждание** точки на плоскости: точка стартует в центре экрана, на каждой итерации выбирается направление шага и точка смещается на заданную величину, оставляя след траектории. Реализованы настраиваемая **величина шага**, **приоритетное направление** и **сила притяжения** к нему с интерактивными слайдерами.

## Функциональные возможности

### Основной функционал

- 🎯 Старт точки в центре области рисования
- 🎲 Случайный выбор направления на каждом шаге
- 📏 Регулировка **величины шага** (слайдер)
- 🧭 **Приоритетное направление** — смещение траектории к заданному углу
- 🧲 **Сила притяжения** к приоритетному направлению (0 — чистая случайность, 1 — только приоритет)
- ✏️ Отрисовка следа и текущей позиции точки

### Дополнительный функционал

- ⏸️ Пауза и продолжение симуляции
- 🔄 Сброс: точка в центр, очистка следа
- ⌨️ Горячие клавиши (Space — пауза, R — сброс)
- 🧪 Юнит-тесты математики модели

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/sluchaynyy-put.git
cd sluchaynyy-put
```

_(После публикации на GitHub замените `USERNAME/sluchaynyy-put` на фактический адрес репозитория.)_

### 2. Создание и активация виртуального окружения

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Дополнительные пакеты не требуются; файл фиксирует использование стандартной библиотеки.

### 4. Запуск программы

**macOS / Linux (одной командой из корня проекта):**

```bash
./run.sh
```

**Или вручную:**

```bash
python main.py
```

### 5. Управление

| Действие | Элемент интерфейса | Клавиша |
|----------|-------------------|---------|
| Величина шага | Слайдер «Величина шага» | — |
| Угол приоритета (0° — вправо, 90° — вверх) | Слайдер «Приоритетное направление» | — |
| Сила притяжения (0…1) | Слайдер «Сила притяжения» | — |
| Сброс | Кнопка «Сброс» | **R** |
| Пауза / продолжить | Кнопка «Пауза» | **Space** |

## Структура проекта

```
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── venv/                  # виртуальное окружение (создаётся локально)
├── src/
│   ├── app.py             # окно и главный цикл анимации
│   ├── models/
│   │   └── animation_model.py   # логика случайного шага
│   ├── renderers/
│   │   └── renderer.py          # отрисовка на Canvas
│   └── widgets/
│       └── controls.py          # слайдеры и кнопки
└── tests/
    └── test_model.py      # тесты модели
```

**Назначение основных модулей:**

- `main.py` — точка входа в программу
- `src/app.py` — класс `App`: окно, таймер, связь модели с интерфейсом
- `src/models/animation_model.py` — класс `RandomWalkModel`: координаты, шаг, приоритетное направление
- `src/renderers/renderer.py` — класс `RandomWalkRenderer`: линия следа и маркер точки
- `src/widgets/controls.py` — класс `ControlPanel`: слайдеры и кнопки управления

Структура разделена по ответственности: модель не зависит от GUI, её можно тестировать отдельно; отрисовка и виджеты не дублируют математику шага.

## Пример использования

### Запуск

```bash
source venv/bin/activate
python main.py
```

### Наблюдение за траекторией

1. Запустите программу — точка начнёт двигаться из центра, оставляя синий след.
2. Увеличьте **величину шага**, чтобы шаги стали длиннее.
3. Задайте **приоритетное направление** 90° и **силу притяжения** 0.5 — путь будет чаще тянуться вверх, но останется случайным.
4. Нажмите **Space**, чтобы поставить симуляцию на паузу; **R** или «Сброс» — вернуть точку в центр.
